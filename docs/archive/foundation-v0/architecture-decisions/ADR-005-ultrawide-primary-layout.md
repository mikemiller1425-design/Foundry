# ADR-005: 49-inch ultrawide is the primary canvas

## Status
Accepted

## Context
The user intends the application to operate as a command-center display. Conventional centered web layouts waste the canvas.

## Decision
Design the canonical interface around 32:9 ultrawide while supporting 16:9 desktop through collapsible panels.

## Alternatives considered
Mobile-first; standard 1440p-only; fixed 5120 layout.

## Consequences
High information density and strong world presence. Requires explicit responsive testing.

## Revisit conditions
Revisit after real usage on target LG display.
