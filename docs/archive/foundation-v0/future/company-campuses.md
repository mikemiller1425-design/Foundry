# Future Concept — Company Campuses

**Status:** Future Registry; not authorized for V1 implementation

## Purpose
Dedicated virtual campuses for real organizations that request and employ agents.

## Underlying architectural insight
A company becomes a first-class tenant with buildings, workforce, budgets, objectives, and service agreements.

## Potential inputs
Company requests, objectives, budgets, service policies, agent availability.

## Potential outputs
Hiring requisitions, projects, performance reports, invoices, capacity plans.

## Dependencies
Multi-tenancy, billing, isolation, governance, Agent Academy, permissions.

## Risks
Data isolation, contractual ambiguity, visual overload, cross-company resource conflicts.

## Possible V1-compatible hooks
V1 should preserve stable IDs, event provenance, capability labels, and audit history so this concept can be added without rewriting the core domain. No dedicated UI, buildings, workflows, or runtime logic are authorized now.

## Explicitly not active
Claude Code must not implement this concept unless the Active Mission is formally amended.
