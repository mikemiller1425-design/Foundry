# Future Concept — Opportunity Center

**Status:** Future Registry; not authorized for V1 implementation

## Purpose
Match current workforce skills and spare capacity to external or internal opportunities.

## Underlying architectural insight
The city can search for productive demand instead of only waiting for assigned work.

## Potential inputs
Skills inventory, capacity, costs, risk appetite, market signals, backlog.

## Potential outputs
Ranked opportunities, missing skills, hiring/training recommendations, expected value scenarios.

## Dependencies
Market Intelligence, Strategic Planning, trustworthy capability metrics.

## Risks
Speculative projections, low-quality leads, legal constraints, incentive misalignment.

## Possible V1-compatible hooks
V1 should preserve stable IDs, event provenance, capability labels, and audit history so this concept can be added without rewriting the core domain. No dedicated UI, buildings, workflows, or runtime logic are authorized now.

## Explicitly not active
Claude Code must not implement this concept unless the Active Mission is formally amended.
