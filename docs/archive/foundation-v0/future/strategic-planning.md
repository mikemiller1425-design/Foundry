# Future Concept — Strategic Planning

**Status:** Future Registry; not authorized for V1 implementation

## Purpose
Evaluate opportunities against current skills, capacity, budget, risk, and long-term goals.

## Underlying architectural insight
Recommendation is a distinct governance function, not raw market discovery.

## Potential inputs
Opportunity records, workforce, treasury, project portfolio, constraints.

## Potential outputs
Prioritized proposals, resource plans, defer/reject decisions.

## Dependencies
Opportunity Center, Treasury, portfolio model, scenario analysis.

## Risks
Over-centralization, false precision, strategy driven by flawed forecasts.

## Possible V1-compatible hooks
V1 should preserve stable IDs, event provenance, capability labels, and audit history so this concept can be added without rewriting the core domain. No dedicated UI, buildings, workflows, or runtime logic are authorized now.

## Explicitly not active
Claude Code must not implement this concept unless the Active Mission is formally amended.
